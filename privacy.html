Privacy Policy

Last updated: 11 October 2026

This policy covers two things: the "Tappy Things" app, a private tool the channel owner uses to manage the Tappy Things YouTube channel, and this website.

Who is responsible

Tappy Things is run by one person, the owner of the Tappy Things YouTube channel. Contact: minhhien2008z@gmail.com

What the app is

The app is an automation that runs on the owner's own computer. It is used only by the owner, with the owner's own Google account. It is not offered to the public, and no other person can sign in to it.

Google data the app accesses

The app uses Google APIs only for the owner's own account:

  • YouTube Data API: to upload the owner's videos and thumbnails to the owner's channel and set their title, description and settings.
  • YouTube Analytics API: to read the owner's own channel statistics (views, watch time) for a weekly report.
  • Gmail API: to send status and report emails from the owner's address to the owner. The app does not read, change or delete any email.

What the app does not do

  • It does not collect, store or process data about viewers, subscribers, commenters or any other person.
  • It does not sell, rent or share any data with anyone.
  • It does not use any data for advertising or to train AI or machine-learning models.

How data is stored and protected

The Google authorisation tokens are stored encrypted on the owner's own computer and are never published or sent to any third party. Channel statistics are used to write the weekly report and are kept only on the owner's computer and in the owner's own mailbox.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

The app uses YouTube API Services. By using it, the owner agrees to be bound by the YouTube Terms of Service. Google's own handling of data is described in the Google Privacy Policy.

Removing access

The owner can remove the app's access at any time on the Google security settings page: myaccount.google.com/permissions. Removing access stops the app from working; the stored tokens then become useless and are deleted from the owner's computer.

This website

This website is a few static pages. It has no accounts, no forms, no cookies and no analytics, and it does not collect personal information. It is hosted on GitHub Pages; GitHub may record technical data such as IP addresses in its server logs, as described in the GitHub Privacy Statement.

Children

Tappy Things videos are made for children and are watched on YouTube, which applies its own rules for made-for-kids content. Neither the app nor this website collects any information from children.

Changes

If this policy changes, the new version will be posted on this page with a new date.
